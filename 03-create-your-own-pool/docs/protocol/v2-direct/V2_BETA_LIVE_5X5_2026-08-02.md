# V2 Beta Live 100,000-Capacity 5x5 Exploratory Report

**Date:** 2026-08-02

**Verdict:** protocol story succeeded; end-user performance qualification failed.

**Claims:** explicitly unqualified beta, zero confirmation, not mined, not production qualified.

This report records a real public-Chipnet exploratory run. It is deliberately
not a semantic or performance qualification bundle: transport and recovery
fixes were committed between actions, the final candidate did not produce all
ten actions from one exact clean commit, and the measured public-provider
command latency exceeded the mandatory `p95 <= 10,000 ms` gate.

## Performance blocker

Local proving is already in the intended seconds range. The blocker is the
mandatory independent public-provider zero-conf observation of these near-limit
transactions. After the bounded read-only convergence implementation, the last
three literal one-command withdrawals completed in 11,997 ms, 14,100 ms, and
12,737 ms process wall time (internal command totals 11,580 ms, 13,683 ms, and
12,319 ms). This is a real failure of the `p95 <= 10,000 ms` gate, not a test
failure to waive. Three samples are also insufficient for the required 20-sample
percentiles.

The final candidate therefore still requires a new one-commit clean run and a
20-sample-per-kind real performance campaign. Do not create a qualifying bundle,
switch a playground, or claim the end-user CLI objective complete unless both
`p50 <= 5,000 ms` and `p95 <= 10,000 ms` independently verify without weakening
the two-provider exact-readback contract.
