# ShieldKit Protocol V2 Direct — Requirement Matrix

**Status date:** 2026-07-29
**Scope:** `03-create-your-own-pool/` in branch `feat/v2-direct-20260728`
**Authority:** `IMPLEMENTATION_PLAN.md`; this matrix is an execution tracker, not a qualification claim.

## Reading this matrix

`Missing` means the required V2 Direct scaffold is absent, or only a legacy
component exists. `Partial` means a V2 Direct local scaffold/test source exists but
the listed requirement also needs missing integration, immutable artifacts, or
qualification evidence. `Existing` means a current repository component supplies
the stated *scaffold*, never that it satisfies the V2 requirement unless the
evidence column says so. The V2 Direct sources and documents listed here are
tracked development-only inputs; `.codex-build/` is ignored local
development-artifact storage. Source tracking alone passes or qualifies no row.

The exact intended paths below are deliberate ownership boundaries for the V2 work;
they do not authorize substituting the similarly named V1 modules. Evidence artifacts
are profile-specific and must be immutable, signed where required, and referenced by
their SHA-256 from the final instance descriptor.
